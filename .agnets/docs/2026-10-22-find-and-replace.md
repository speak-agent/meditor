# 共享文档查找与替换

状态：首版基础编辑能力的部分实现；不代表 A01–A13 或完整产品验收通过。

## 交付行为

文档包新增大小写敏感的 UTF-8 字面量查找和替换，不把正则符号解释为模式。共享 KMP 扫描支持前后导航、非重叠匹配、精确计数与有限结果返回；反向导航从给定位置之前开始。扫描与返回 UTF-16 偏移均为线性工作，不为每个匹配重扫整份前缀。全部替换流式组装结果，不为几百万次匹配建立同样大小的匹配数组。

`document.find` 与 `document.replace` 都要求当前 revision；过期请求在修改前拒绝。默认使用原始 UTF-8 字节，显式 `coordinateSpace: display` 才使用隐藏 BOM、CRLF 显示为 LF 的坐标。返回的匹配同时包含所选空间的 UTF-8 与全局 UTF-16 范围，以及原文 `rawStart` / `rawEnd`。GUI 用同一命令读取匹配和执行替换，不维护另一份替换算法。

GUI 通过工具栏“查找”或 Ctrl/Cmd+F 打开框架的搜索对话框，自动聚焦查询框，Tab 可访问操作，Escape 返回此前的编辑区焦点。提供匹配总数、前后循环、单个/全部替换和明确错误状态。单个替换用返回的 `nextStart` 跳过新插入内容，避免再次替换刚插入的同名文本。已打开的查询值仅存当前内存会话，不写历史或上传。

匹配以搜索底色标记，当前匹配采用选择背景；内容 revision 改变时清理旧标记，旧 revision 的绘制/选择请求不会覆盖新快照。修改搜索文字不会改文档；替换先修改未保存文档，用户保存后才写磁盘。有实际变化的每次全部替换只进入一次撤销历史。显示空间的新增换行采用当前偏好，BOM 和未替换的混合换行按原字节保留；已有单独 CR 文件仍可查找，但 GUI 替换按钮禁用。

搜索对话框有独立深浅底色，桌面打开时保留侧栏和编辑区几何位置。检查了当前七类语法文字与搜索/选择底色的颜色组合，计算的最小对比度分别为深色约 4.99、浅色约 4.68；这不是所有控件、字体、合成层或平台的完整可访问性验收。进入搜索结束编辑区组合输入会话时清理撤销分组，后续输入不会错误并入上一次组合操作。刷新文本快照时选择位置会落在合法 UTF-16 边界；替换响应的位置映射回显示光标，避免旧选择落入新 emoji 的代理对。

## CLI 契约示例

在同一个 `meditor serve --stdio` 会话中打开文档，再使用其 document 和 revision：

```json
{"command":"document.find","params":{"document":"<id>","revision":1,"query":"needle","coordinateSpace":"display","limit":1000}}
{"command":"document.replace","params":{"document":"<id>","revision":1,"query":"needle","replacement":"answer","coordinateSpace":"display","all":true}}
```

查询不能为空且最多 4096 UTF-8 字节；返回 `limit` 为 1–10000，默认 1000，`total` 为请求起点/方向范围内的精确匹配数，`truncated` 只说明匹配数组受限。GUI 高亮默认最多 1000 个，继续导航可访问其余匹配。`start` 以所选空间的 UTF-8 字节计，必须处在字符边界；反向默认起点为文本末尾。全部替换覆盖全文，不能同时传入 start/direction。替换结果最多 32 MiB，超过上限返回 `document-too-large`，不提交部分修改。替换响应给出次数，单个替换另给出 `nextStart`；无实际变化不增加 revision，也不声明 document-change 效果。

## 验证与边界

覆盖 Unicode 前后坐标、500 组正反向标准字节查找对照、重复字符长模式、字面量特殊符号、BOM/混合换行、过期 revision、无变化替换、原子超限拒绝和打包消费者调用。真实 headless 工作台检查六组尺寸/语言布局、初始焦点、匹配绘制、循环、单个替换的新光标、只读禁用、Escape 返回及一次撤销。Linux 原生驱动增加实际键盘查找、Tab、替换、保存和撤销，并保留合成截图，纳入 CI。

当前扫描仍同步执行，尚未证明大文件输入延迟/取消预算；跨进程 GUI/CLI 会话、恢复、工作区切换时的未保存数据保护、其他编辑路径与读入上限的一致性，以及四端原生 IME/读屏/视觉验收仍需完成。不要以本轮功能或绿色编译矩阵代替这些要求。
