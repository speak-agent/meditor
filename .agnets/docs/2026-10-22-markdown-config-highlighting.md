# Markdown 与生态配置基础高亮

状态：H01 的后续部分实现，接续 [C++ 词法层](2026-10-22-cpp-highlighting.md)。这不是完整多语言语法支持或四端产品验收结论。

## 已接入的行为

同一个 `meditor.syntax` 模块增加 Markdown、JSON、JSONC 与 TOML；GUI 与 `document.highlight` 自动按文件名识别。`.md` / `.markdown`、`.json`、`.jsonc`、`.toml` 和名为 `mcpp.lock` 的文件有基础着色。其他格式的 `.lock` 不会被误判为 TOML。新增实现仍是文档包内的 `.cpp` 实现单元，没有引入 GUI 或平台依赖。

- JSON：双引号字符串、对象键、数值、true/false/null；JSONC 额外识别行/块注释，块注释状态跨行传播。严格 JSON 不把注释当合法词法类型。
- TOML：表/数组表头、常见裸键/引号键、字符串、数值、布尔值、注释，含基本/字面量多行字符串。引号内的 `#`、`=` 和 `]` 不作为外部注释、赋值或表头结束符处理。
- Markdown：ATX 标题、列表/引用标记、同行强调、链接/图片语法与反引号代码片段。围栏按字符、长度和缩进维护状态；标为 cpp/c++/cppm/c、json/jsonc、toml 的围栏复用对应词法器，未知语言按代码文本着色。围栏关闭清除内部词法状态，编辑/移除开闭围栏会使后续状态重算。内容仍是可编辑原文，不是执行环境或 HTML 预览。

桌面状态栏显示当前识别的语言，未知文件显示本地化的纯文本标签。统一角色新增 key、heading、emphasis、link、code、marker，沿用深浅主题色和同一份 attributed paragraph。范围仍是单行 UTF-8 字节位置，GUI 转成 UTF-16 属性范围，不改变选择或文档 revision。CLI 原有 schema、有限行查询、4096-token 返回上限和 revision 契约保持不变；语言与角色名统一由模块提供。

## 有界工作与测试

除既有全文/单行/token 预算，Markdown 对单行分隔符搜索设置工作预算。大量未闭合开括号或其他病态文本不能触发无界的重复后缀扫描；预算耗尽时整份文档退回纯文本，使用现有 en/zh 可见受限提示。提示不再把所有超限原因写成“大文件”。这不是输入延迟预算已经达标的声明。

文档包测试覆盖不同配置语法的注释差异、TOML 多行与引号内分隔符、Markdown 内嵌语言/围栏长度/缩进、UTF-8 token 边界、病态搜索降级，以及每种新增语言 200 次随机行编辑后增量与冷扫描一致性。

GUI headless 测试检查新增语言在深浅主题、手机/桌面尺寸下实际绘制快照中的 UTF-16 范围，并执行选择、删除和撤销，确认原文保留。CLI 回归检查识别、角色、revision 及既有错误/限额契约。独立文档包消费者也导入词法模块并调用 Markdown/JSON 组合扫描，验证无需 GUI 的公共模块消费与实现链接。检查发现词法模块尚未被文档包公共根导出，已补 `export import meditor.syntax`，避免依赖源码可见性掩盖打包接口缺失；新增 `scripts/test_document_package.py` 在隔离目录复制实际打包的接口与编译库，确认不含实现源码，再编译运行同一消费者。本地 Linux 已通过；该脚本加入三端原生 CI。它不代表所有组件、四端或产品安装包的 A13 完整验收。Linux 原生窗口驱动新增固定合成的 Markdown/JSON/TOML 场景与主题参数，CI 执行真实键盘编辑、保存、撤销/重做并保留截图；它仍不证明原生 IME、手机或其他平台的呈现。
